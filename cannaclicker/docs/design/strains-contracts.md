# Strains and Contracts

## Strains

Pro Run kann genau eine Strain aktiv sein. XP und Level bleiben permanent, die aktive Auswahl wird bei Prestige zurueckgesetzt.

| Strain | Archetyp | Fokus |
| --- | --- | --- |
| Sativa Spark | Active | BPC, Klicks, Event-Rewards |
| Indica Canopy | Idle | BPS, Offline-Cap |
| Hybrid Bloom | Hybrid | Buffdauer, Eventfenster |
| Ruderalis Loop | Automation | Auto-Klick, Automationsanteil |
| Deep Root | Prestige | Ascension-Ertrag, Strain-XP |

Strain-XP kommt aus Klicks, Events, Kaeufen, Upgrades und Research. Level 1-3 geben kleine, klar lesbare Boni.

## Contracts

Contracts sind Run-Auftraege. Es gibt immer drei Angebote: Easy, Medium und Hard. Nur ein Contract kann gleichzeitig aktiv sein.

Rewards:

- Contract Tokens fuer Greenhouse Rooms.
- Kleine Next-Run-Buffs.
- Cosmetics/Badges fuer harte oder thematische Contracts.

Nicht vorgesehen:

- massive direkte Ascension-Seed-Rewards.
- mehrere parallele Contracts.
- Contracts, die externe Anleitung erfordern.

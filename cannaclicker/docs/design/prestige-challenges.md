# Prestige Challenges

Prestige Challenges erzeugen neue Runs aus vorhandenen Systemen. Eine Challenge ist aktiv, bis sie abgeschlossen, abgebrochen oder beim Prestige nicht erfuellt wird.

## Challenges

| Challenge | Regel | Reward |
| --- | --- | --- |
| No Events | keine Event-Spawns | kleiner globaler Bonus, Badge |
| Manual Garden | passive Produktion deaktiviert | kleiner Klickbonus, Skin |
| Silent Greenhouse | Abilities deaktiviert | Offline-Cap, Theme |
| Budget Run | Shopkosten steigen | kleiner globaler Bonus, Frame |
| Risk Market | Events fokussieren Risk | Eventreward-Bonus, Badge |
| Tiny Pot | max. 80 Kopien pro Item | kleiner globaler Bonus, Skin |

## UX-Regeln

- Start nur, wenn freigeschaltet.
- Eine aktive Challenge gleichzeitig.
- Abbruch ist moeglich.
- Rewards sind klein, sichtbar und dauerhaft.
- Challenge-Regeln duerfen nicht heimlich im Hintergrund wirken; UI zeigt Aktivstatus.

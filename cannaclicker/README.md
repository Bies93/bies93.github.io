# BiesyClicker

Sowas wie CookieClicker in grün.

Ein simples Idle Game mit legalen Pflanzen, gebaut für Bies, Freunde und Bekannte.

Creator: Freiherr Bies

## Lokal starten

- Node.js 20 or newer
- npm

Vom Repository-Root aus:

```bash
npm --prefix cannaclicker install
npm --prefix cannaclicker run dev
npm --prefix cannaclicker run build
npm --prefix cannaclicker run preview
```

Zum Veröffentlichen reicht der normale Build. Die GitHub-Pages-Dateien entstehen in `cannaclicker/dist`.
